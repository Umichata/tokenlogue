# Tokenlogue

Tokenlogue — защищённый мультиплатформенный клиент OpenRouter с локальной
историей диалогов и настраиваемыми лимитами токенов и расходов.

## Возможности

- локальный вход по четырёхзначному PIN;
- хранение API-ключа в платформенном SecureStorage;
- выбор бесплатного или платного режима и модели для каждого чата;
- несколько локальных чатов с полной историей сообщений;
- отдельный автоматически сохраняемый черновик каждого чата с восстановлением
  после переключения и перезапуска;
- лимиты токенов, максимальной длины ответа и расходов для отдельных чатов;
- консервативное резервирование бюджета до завершения запроса;
- безопасная обработка неопределённого результата запроса без автоматического
  освобождения резерва.

История сохраняется в приватной SQLite-базе приложения без дополнительного
шифрования содержимого. PIN в открытом виде не хранится. API-ключ хранится
отдельно через защищённое хранилище платформы.

Черновики хранятся в той же локальной SQLite отдельно от истории. Они не
передаются модели и не расходуют лимиты. Черновик очищается при успешной
локальной регистрации отправки только для отправленной ревизии текста;
ошибки предварительной проверки и отмена платного запроса его сохраняют.

## Запуск из исходников

- Python 3.12;
- [uv](https://docs.astral.sh/uv/).

Установка окружения и локальный запуск:

```bash
uv sync
uv run flet run
```

Запуск тестов:

```bash
uv run python -m unittest discover -s tests -v
```

## Платформы

Целевые платформы проекта: Linux, Windows и Android. Готовые установочные
пакеты пока не опубликованы.

## Linux AppImage

Для Linux x86_64 с поддержкой x86-64-v2 подготовлена тестовая AppImage-сборка
`14b87ac`. Python, uv и Flutter SDK для её запуска устанавливать не нужно.
Нужны системная GTK3 с её
зависимостями и работающий Secret Service для защищённого хранения API-ключа.

[Инструкция запуска и требования](docs/linux-appimage.md) описывает проверку
SHA-256, обычный запуск и запуск без FUSE. Файл пока распространяется как
диагностический артефакт GitHub Actions; публичный prerelease готовится.

[Сборка 34439008120](https://github.com/Umichata/tokenlogue/actions/runs/34439008120)
прошла на Ubuntu 22.04 с проверкой состава Python-пакетов по `uv.lock` и
ABI-пределом `GLIBC_2.35`. Встроенный реестр notices проверен в AppDir и
извлечённом AppImage. Он охватывает 75 компонентов и 85 проверяемых объектов.
[Матрица 34439720271](https://github.com/Umichata/tokenlogue/actions/runs/34439720271)
успешно проверила тот же AppImage в Ubuntu 22.04, Ubuntu 24.04 и Fedora 44,
включая обязательные проверки системных GVfs и IBus. Дополнительная ручная
проверка на Linux Mint 22.3 Cinnamon/X11 подтвердила стабильную работу.

[Сверка нового артефакта](docs/releases/14b87ac-notice-audit.md) подтверждает
совпадение контрольных сумм и отсутствие прежнего пути runner в notices.
Подготовка исходных материалов сторонних компонентов остаётся отдельным
незавершённым пунктом перед публичным preview.

AppImage не подписан и не содержит автоматического обновления. Проверки в
контейнерах не подтверждают работу во всех desktop-окружениях, Wayland и со
всеми видеодрайверами. Состояние подготовки и точные идентификаторы приведены в
[карточке тестового релиза](docs/releases/v0.1.0-linux-preview.1.md).

Инфраструктура сборки и проверки описана в
[packaging/linux/appimage/README.md](packaging/linux/appimage/README.md).
DEB и RPM пока не собраны; файлы в `packaging/linux/` сохраняют метаданные для
этих форматов.

OpenRouter является сторонним сервисом. Проект Tokenlogue не связан с
OpenRouter и не аффилирован с ним.
