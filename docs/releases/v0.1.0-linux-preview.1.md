### Requirements and version differences

This unsigned preview requires Linux x86_64 with x86-64-v2 support, system
GTK3, working graphics and a Secret Service provider. Python is included.
There is no automatic updater. History and drafts are stored locally without
additional database encryption.

Wayland compatibility has not been verified for this older version.
The compact `⋮` menu and replacement runtime described for `1472c00`
were added after this preview. Follow the current guide when using that
newer file.

### Licenses and sources

This AppImage includes its own component notice index and original license
texts. A [separate historical source collection](14b87ac-source-materials.md#lang-en)
was assembled for it. The collection is incomplete. It lacks a confirmed list of the Alpine
packages used for the older runtime and some external Flutter SDK sources.
For version `1472c00`, see the [source materials guide](../source-materials.md#lang-en).
