### What to know about this version

This unsigned AppImage includes Python. It requires Linux x86_64 with x86-64-v2 support, GTK3, working graphics and a Secret Service provider. There is no automatic updater. Its chat history and drafts are stored locally without the additional content encryption used by later versions.

Wayland operation was not checked for this preview. The compact `⋮` menu and replacement startup runtime introduced in a subsequent preview were absent from this package. Do not use this record to infer the behavior or protection of current packages.

### Особенности этой версии

Неподписанный AppImage содержит Python. Ему нужны Linux x86_64 с поддержкой x86-64-v2, GTK3, рабочая графика и поставщик Secret Service. Автоматического обновления нет. История чатов и черновики сохраняются локально без дополнительного шифрования содержимого, используемого более поздними версиями.

Работа с Wayland для этой сборки не проверялась. Компактное меню `⋮` и новый runtime запуска, появившиеся в следующей предварительной версии, в этом пакете отсутствовали. Эти сведения не описывают поведение и защиту текущих пакетов.
