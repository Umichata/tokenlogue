# Tokenlogue 0.1.0. Linux preview 1

Статус на 10 сентября 2026 года. Техническая проверка кандидата `14b87ac`
завершена. Пройдены сборка, матрица трёх userspace и сверка встроенного
реестра notices. Пользователь подтвердил стабильную работу AppImage.

Подготовка соответствующих исходников и материалов пересборки сторонних
компонентов остаётся открытой. В реестре сохранён статус
`source_materials: REVIEW_REQUIRED`. Предлагаемое имя будущего тега
`v0.1.0-linux-preview.1`. Версия внутри приложения остаётся `0.1.0`.
При сверке публичный GitHub API вернул пустые списки тегов и релизов.

## Назначение сборки

Тестовая Linux x86_64 сборка Tokenlogue предоставляет локальные чаты,
сохраняемые черновики, вход по PIN, защищённое хранение API-ключа и лимиты
токенов и расходов. Она использует GTK3 и desktop-модули целевой ОС,
включая GVfs и IBus. Python и Flutter включены в AppImage.

[Инструкция запуска](../linux-appimage.md) описывает системные требования,
проверку контрольной суммы и режим запуска без FUSE.

## Ограничения

- Процессор должен поддерживать x86-64-v2. В реестре закреплён CPython
  3.12.14 из PBS 20260901 для `x86_64_v2`.
- GTK3, графический стек и Secret Service предоставляет целевая ОС.
  Контейнерные проверки используют Xvfb и программный рендеринг.
  Совместимость со всеми Wayland-сессиями и видеодрайверами не установлена.
- AppImage не подписан и не содержит автоматического обновления.
- Воспроизводимость подтверждена для двух упаковок внутри одного запуска.
  Побитовое совпадение разных Flet-сборок и runner images не установлено.
- История и черновики в SQLite дополнительно не шифруются.
- Исходное доверие к закреплённым build tools основано на release assets
  и SHA-256. Наличие подписанного provenance не заявляется.
- Исправление прежних предупреждений Flutter о view/engine не заявляется.

## Продолжение подготовки

Технические проверки и notices для этого файла завершены. Следующая работа
состоит в подготовке исходных материалов по фактическому реестру компонентов
и закрытии `source_materials: REVIEW_REQUIRED`. После проверки полного
комплекта можно подготовить draft prerelease.

Документационный коммит не требует новой сборки и матрицы. Если выбранный
AppImage сохраняет свои байты, будущий тег приложения должен указывать на
`14b87ac03e5c03c2ed9c4acf6caae29daa39d20e`, даже если документация обновлена
позднее. Изменение содержимого AppImage потребует нового коммита сборки,
проверок и обновления этой карточки.

[Аудит старого файла 4a498ad](4a498ad-notice-audit.md) сохранён как история
обнаруженных пропусков. Его контрольные суммы относятся только к старому файлу.
