<a id="ℹ-особенности-этой-версии"></a>
## <img src="../assets/ui/section-mark.svg" alt="" width="20" height="20"> ℹ️ Особенности этой версии

Неподписанный AppImage содержит Python. Ему нужны Linux x86_64 с поддержкой x86-64-v2, GTK3, рабочая графика и поставщик Secret Service. Автоматического обновления нет. История чатов и черновики сохраняются локально без дополнительного шифрования содержимого, используемого более поздними версиями.

Работа с Wayland для этой сборки не проверялась. Компактное меню `⋮` и новый runtime запуска, появившиеся в следующей предварительной версии, в этом пакете отсутствовали. Эти сведения не описывают поведение и защиту текущих пакетов.

<a id="-исходники-и-лицензии"></a>
## <img src="../assets/ui/section-mark.svg" alt="" width="20" height="20"> Исходники и лицензии

AppImage содержит индекс уведомлений о компонентах и оригинальные тексты лицензий. Его <a href="14b87ac-source-materials.ru.md#russian" title="исторический комплект исходников">исторический комплект исходников&nbsp;<img src="../assets/ui/inline-link.svg" alt="" width="17" height="17"></a> сохраняет соответствующие материалы приложения и зависимостей. Комплект не подтверждает полную пересборку прежнего runtime и инструментов Flutter.

Более поздний [опубликованный базовый набор](https://github.com/Umichata/tokenlogue/releases/tag/v0.1.0-linux-preview.986c6ad) содержит замены некоторых зависимостей и отдельный комплект runtime. <a href="../source-materials.ru.md#russian" title="Руководство по исходным материалам">Руководство по исходным материалам&nbsp;<img src="../assets/ui/inline-link.svg" alt="" width="17" height="17"></a> объясняет связь каждого набора с пакетом приложения.
