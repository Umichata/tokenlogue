Для Ubuntu проверено наличие build rules, control и changelog в Debian tar
или соответствующем diff. Вытесненный `libgcrypt20` 1.9.4-3ubuntu3.2 получен
из [сохранённой публикации Launchpad](https://api.launchpad.net/1.0/ubuntu/+archive/primary/+sourcepub/18430640).
Подписи `.dsc` сохранены, но ключи подписантов отдельно не аутентифицировались.
Собственные хеши GitHub source archives фиксируют полученные байты и не
объявляются подписанным provenance.

`_dbm` включает статический Berkeley DB 6.0.19: исходник и рецепт PBS вложены.
`_crypt` использует `libcrypt.so.1`, включённую из Ubuntu `libxcrypt`
1:4.4.27-1; её source package также вложен. Удалённый `_tkinter` не включён
в покрытие статических зависимостей Python. Действительные link records и
параметры сборки сохранены в `evidence/PYTHON.json`.

## Проверки

- Все 319 записей загруженных файлов сверены с их размерами и SHA-256.
- Проверены форматы tar/ZIP, CRC итогового ZIP и целостность 707 файлов описи.
- Опциональная сверка с исходным AppImage подтвердила прежний SHA-256.
- Проверяющий скрипт принимает целый комплект и отклоняет повреждение,
  отсутствие файла и выход пути за корень. Ruff lint/format пройдены.
- Приложение, скачанные build scripts, контейнерные сборки и workflow не
  запускались. Пользовательские БД, keyring и API-ключи не использовались.

После распаковки выполняется только проверка чтением:

```bash
cd Tokenlogue-14b87ac-source-materials
python3 verify_materials.py
```

Ожидается:

```text
Integrity: PASS (707 files)
Source completeness: REVIEW_REQUIRED
Rebuild verification: NOT_RUN
```

## Открытые ограничения

1. **Привязка Alpine inputs старого runtime не доказана.** Его Dockerfile
   использует изменяемый `alpine:3.21` и незакреплённый `apk add`. Собраны
   исторические рецепты musl 1.2.5-r9, zlib 1.3.1-r2, zstd 1.5.6-r2 и
   mimalloc2 2.1.7-r0; исходники и патчи совпали с SHA-512 APKBUILD.
   Однако выбор исторического рецепта по дате не заменяет APK inventory
   исходной сборки. [Upstream run 19184380946](https://github.com/AppImage/type2-runtime/actions/runs/19184380946)
   найден, но запрос логов вернул HTTP 403 с требованием прав администратора
   чужого репозитория. Эти материалы отмечены как исторические кандидаты.
2. **Комплект SDK не является полностью автономным.** Сохранены точный engine
   `DEPS` и его 109 разрешённых ссылок; не все внешние Git/CIPD входы вложены.
   Сборка Flutter engine без сети из одного этого ZIP не заявляется.
3. **Пересборка не выполнялась.** Bootstrap toolchain, relinking, font
   subsetting и побитовое совпадение новой сборки с AppImage не проверялись.

Сбор перечисленных материалов завершён. Общая полнота соответствующих
исходников остаётся `REVIEW_REQUIRED`; этот статус не заменён проверкой хешей.
Для runtime нужно подтверждение исходных APK inputs либо собственная сборка
с закреплёнными входами. Собственная сборка изменит AppImage и потребует
повторной технической проверки. Для текущего документа повтор workflow
не требуется.
