# Как пользоваться Tokenlogue Dart

Установите Dart APK на Android ARM64. Android хранит профили Dart и Python в отдельных каталогах приложений. Для обновления Dart сохраните установленное приложение и откройте APK с той же Dart-подписью.

## Подключение сервиса

Начните с ключа OpenRouter с префиксом `sk-or-v1-` или ключа VSEGPT с началом `sk-or-vv-` либо `sk-or-vis`. Нажмите **Проверить ключ**, затем задайте PIN приложения из четырёх цифр. На странице провайдеров у каждого сервиса своя форма. Если VSEGPT ограничивает проверку баланса, можно явно сохранить непроверенный ключ. Загрузка каталога сама по себе не подтверждает ключ.

Для новых чатов можно установить **Ручной выбор**, **OpenRouter** или **VSEGPT**. У существующего чата сохраняется своё подключение.

Если сервис не успел ответить или просит подождать, проверьте ключ позже. Чтобы сохранить ключ VSEGPT после неудавшейся проверки, выберите **Сохранить непроверенный ключ**. Если сервис отклонил ключ, замените его.

## Как пользоваться чатом

Выберите **Новый чат**, сервис, модель и лимиты. OpenRouter предлагает бесплатный и платный режимы. VSEGPT сразу открывает платный каталог. У бесплатного маршрутизатора OpenRouter нулевые предельные цены. Через **⋮** можно посмотреть подключение чата или выбрать другого провайдера. Перед подтверждением проверьте новую модель и бюджет.

Для платного чата VSEGPT введите бюджет больше нуля в RUB. Для платного чата OpenRouter приложение предлагает 1 USD. Эту сумму можно изменить до создания чата. У бесплатного чата есть только лимиты токенов. Новый платный чат запрашивает подтверждение перед отправкой. Изменить эту настройку можно в самом чате.

Если для новых чатов задан **Ручной выбор**, кнопка **Новый чат** открывает список провайдеров поверх текущей переписки. Нажмите **Отмена**, чтобы вернуться к черновику. Во время выбора модели через нижнее меню можно открыть статистику токенов и расходы. При возврате на главную откроется выбранный чат.

Черновик принадлежит выбранному чату. При отправке нужный контекст переписки передаётся выбранному сервису. Копируйте сообщение или блок кода кнопкой рядом с ним. Удаление чата также удаляет его местную историю, черновик и статистику.

В открытом чате выберите **⋮ → Обновить ключ и баланс**. В меню видны провайдер, маска сохранённого ключа и результат проверки. Язык интерфейса можно сменить также на страницах «Провайдеры», «Токены» и «Расходы».

## Лимиты и расходы

На странице «Провайдеры» OpenRouter может сообщить, сколько бесплатных запросов осталось на текущие сутки по UTC. Приложение показывает этот счётчик только при наличии данных сервиса.

Баланс аккаунта, лимит ключа OpenRouter и бюджет чата показывают разные суммы. Оценка токенов и расходов приблизительна. При приближении к порогу предупреждения проверьте суммы, отмените отправку, измените бюджет или явно отправьте запрос. Изменение бюджета не отправляет черновик. Если результат отправленного запроса неизвестен, проверьте его местный резерв перед освобождением. Освобождение резерва не возвращает деньги у провайдера.

На страницах **Токены** и **Расходы** выберите провайдера, модель и период. Нажмите на день для просмотра подробностей. OpenRouter использует USD, VSEGPT использует RUB. Неизвестные суммы и записи без даты показываются отдельно.

## Защита и восстановление

При возвращении из фона введите PIN приложения. На поддерживаемых устройствах с Android 11 или новее через **Забыли PIN?** можно заново подтвердить личность системным способом и выбрать новый PIN приложения. Отмена до сохранения оставляет прежний PIN. Для системной проверки нужна настроенная блокировка экрана. При восстановлении сохраняется ключ шифрования существующего профиля.

На Android 7–10 системное восстановление PIN недоступно. Нажмите **Отменить восстановление**, чтобы вернуться к обычному входу, и введите прежний PIN приложения.

**Удалить локальный профиль** удаляет ключи провайдеров, материалы защиты, чаты и статистику Dart-приложения. Эта операция необратима. Для завершения введите показанную фразу подтверждения. Совместимое обновление не требует удаления профиля.

После трёх неверных попыток ввести PIN подождите пять минут. Ограничение сохраняется при перезапуске приложения. Если удаление прервалось после подтверждения, снова откройте Tokenlogue. Если появится кнопка **Завершить удаление**, нажмите её.
