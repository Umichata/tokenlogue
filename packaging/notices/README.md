## English

Tokenlogue supplies original third-party notices alongside the software they describe. Android and Linux include the notices relevant to each package.

### Read the original texts

- [libffi 3.4.4](inputs/libffi-3.4.4-LICENSE.txt) belongs to the Android Python runtime.
- [Dart bridge 1.10.0](inputs/dart-bridge-1.10.0-LICENSE.txt) connects the Android Python runtime and Dart.
- KaTeX includes the [MIT license](inputs/flutter_math_fork-0.7.4-katex-LICENSE.txt), [font copyright](inputs/KaTeX-COPYRIGHT.txt) and [SIL Open Font License 1.1](inputs/SIL-OFL-1.1.txt).
- Material Icons includes its [original declaration](inputs/MaterialIcons_LICENSE.txt) and [Google copyright notice](inputs/MaterialIcons-COPYRIGHT.txt).

Legal texts remain complete and unchanged in their original language. The accompanying manifest maps them to exact components and sources. Android uses a subset of Material Icons produced by Flutter. The Linux font matches the original input. These transformations are described separately from the legal texts.

The runtime libffi notice does not identify the library inside the separate CFFI wheel. See [source materials](../../docs/source-materials.md#english) for that distinction and the remaining provenance limits.

## Русский

Tokenlogue поставляет оригинальные уведомления сторонних компонентов вместе с соответствующим программным обеспечением. Пакеты Android и Linux включают относящиеся к ним тексты.

### Оригинальные тексты

- [libffi 3.4.4](inputs/libffi-3.4.4-LICENSE.txt) относится к среде Python для Android.
- [Dart bridge 1.10.0](inputs/dart-bridge-1.10.0-LICENSE.txt) связывает среду Python для Android и Dart.
- Для KaTeX сохранены [лицензия MIT](inputs/flutter_math_fork-0.7.4-katex-LICENSE.txt), [авторские права на шрифты](inputs/KaTeX-COPYRIGHT.txt) и [SIL Open Font License 1.1](inputs/SIL-OFL-1.1.txt).
- Для Material Icons приведены [оригинальная декларация](inputs/MaterialIcons_LICENSE.txt) и [авторские права Google](inputs/MaterialIcons-COPYRIGHT.txt).

Юридические тексты сохранены полностью и без изменений на языке источника. Сопроводительный манифест связывает их с точными компонентами и источниками. Android использует подмножество Material Icons, созданное Flutter. Шрифт Linux совпадает с исходным файлом. Эти преобразования описаны отдельно от юридических текстов.

Уведомление libffi из runtime не определяет библиотеку внутри отдельного wheel CFFI. Это различие и оставшиеся ограничения происхождения описаны в [исходных материалах](../../docs/source-materials.md#russian).
