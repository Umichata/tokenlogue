# AppImage licenses

The AppImage package carries the original licenses and copyright notices for its included software. Tokenlogue's own code uses the <a href="../../../LICENSE" title="MIT license">MIT license&nbsp;<img src="../../../docs/assets/ui/inline-link.svg" alt="" width="17" height="17"></a>.

<a id="-find-the-original-texts"></a>
<a id="-license-files"></a>

## <img src="../../../docs/assets/ui/section-mark.svg" alt="" width="20" height="20"> License files

After extracting your verified AppImage, these paths are relative to its extracted root:

<img src="../../../docs/assets/ui/frame-top.svg" width="100%" alt="">

| Path | What it contains |
| --- | --- |
| `LICENSE` | Tokenlogue's license |
| `THIRD_PARTY_NOTICES.md` | Component index and notice locations |
| `usr/share/doc/tokenlogue/notices.json` | Component mapping, file hashes and source references |
| `usr/share/doc/tokenlogue/licenses/` | Original third-party texts |
| `usr/share/doc/tokenlogue/licenses/supplemental/` | Additional font declaration, attribution and source mapping |

<img src="../../../docs/assets/ui/frame-bottom.svg" width="100%" alt="">

The <a href="../../../docs/linux-appimage.md#english" title="Linux guide">Linux guide&nbsp;<img src="../../../docs/assets/ui/inline-link.svg" alt="" width="17" height="17"></a> covers checksum verification and launch options.

<a id="-read-the-collection"></a>
<a id="-included-components"></a>

## <img src="../../../docs/assets/ui/section-mark.svg" alt="" width="20" height="20"> Included components

The collection covers Python, Flutter and its plugins, native libraries, fonts and the AppImage runtime. Material Icons retains its original declaration and Google attribution. The Linux font matches the original font input. KaTeX license and font notices remain with their corresponding fonts.

Debian copyright files can mention source-package files that are absent from the AppImage. Python's upstream license collection can also describe optional modules that are not included. Use the component mapping to identify the software actually supplied. A license reference does not imply that an optional feature is available in Tokenlogue.

Original legal texts are neither translated nor shortened. Their terms take precedence over this explanation. Source archives are separate from the license collection. See <a href="../../../docs/source-materials.md#english" title="available source materials and their limitations">available source materials and their limitations&nbsp;<img src="../../../docs/assets/ui/inline-link.svg" alt="" width="17" height="17"></a>.
